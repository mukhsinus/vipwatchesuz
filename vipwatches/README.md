# VIPWATCHES_UZ — сайт бутика часов

React + TypeScript + Vite + React Router. Двуязычный (RU/UZ), с каталогом, корзиной и заявкой.

## Запуск

```bash
npm install
npm run dev
```

Откроется на http://localhost:5173

Сборка для продакшена: `npm run build` → папка `dist/`

## Что где лежит

```
src/
  data/site.ts          ← ТЕЛЕФОН, TELEGRAM, INSTAGRAM, КАРТА — правьте здесь
  data/products.ts      ← товары каталога
  data/promos.ts        ← акции
  i18n/translations.ts  ← все тексты сайта на RU и UZ
  i18n/LanguageContext.tsx
  context/CartContext.tsx
  components/           ← шапка, подвал, карточка товара, часы, иконки
  pages/                ← Главная, Каталог, Товар, Акции, О магазине, Контакты, Корзина, 404
  styles/global.css     ← вся вёрстка, палитра в :root наверху файла
public/images/products/ ← сюда фото часов
```

## Первые шаги после переноса

**1. Контакты.** Откройте `src/data/site.ts` — там телефон, ссылки на Telegram и Instagram, ссылка на карту. Сейчас стоят данные из профиля; проверьте и поправьте.

**2. Карта.** В Google Maps найдите шоурум → «Поделиться» → «Встроить карту» → скопируйте адрес из `src="..."` и вставьте в `mapEmbed`.

**3. Товары.** В `src/data/products.ts` сейчас 10 демо-моделей с примерными ценами. Замените на реальные. Поля:

- `id` — латиницей, без пробелов, попадает в адрес страницы (`/catalog/rolex-datejust-41`)
- `price` — число в долларах
- `category` — `classic`, `sport` или `casual`
- `mechanism` — `quartz` или `automatic`
- `image` — путь к фото
- `desc` — описание на двух языках
- `isNew` — показать метку «Новинка»
- `featured` — показать на главной
- `popularity` — число для сортировки «по популярности»

**4. Фото.** Положите файлы в `public/images/products/` с теми именами, что указаны в `image`. Пока файла нет, вместо картинки рисуется заглушка с силуэтом часов — сайт не ломается.

**5. Тексты.** Все надписи — в `src/i18n/translations.ts`. Русский объект `ru` задаёт список ключей, `uz` обязан содержать те же ключи: если забудете один, TypeScript покажет ошибку при сборке.

## Куда уходит заявка

Сейчас заявка формируется на клиенте: после отправки формы покупатель видит экран «Заявка принята» и кнопку, которая открывает Telegram с готовым текстом заказа. Сам текст пишется в консоль браузера.

Чтобы заявки приходили на сервер, найдите в `src/pages/CartPage.tsx` функцию `handleSubmit` — там оставлен закомментированный пример запроса `fetch("/api/orders", ...)` в том месте, где его нужно вставить.

## Полезно знать

- Язык и корзина сохраняются в `localStorage` — при перезагрузке не теряются.
- Палитра взята из интерьера шоурума: изумрудный, латунь, кремовый. Все цвета — переменными в `:root` в начале `global.css`, меняются в одном месте.
- Часы на главной идут по реальному времени Ташкента.
